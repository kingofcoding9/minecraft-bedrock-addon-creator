Entity Basics
Understanding entity structure, files, and basic concepts
• beginner ⏱️ 20 min
▼

Entities in Minecraft Bedrock are complex objects that can move, interact, and exhibit behaviors. They consist of two main components:

  • Behavior Pack Entity: Defines logic, AI, components, and server-side behavior
  • Resource Pack Entity: Defines visuals, models, textures, and animations

Basic Entity Structure

{
  "format_version": "1.19.0",
  "minecraft:entity": {
    "description": {
      "identifier": "mypack:custom_entity",
      "is_spawnable": true,
      "is_summonable": true
    },
    "components": {
      "minecraft:health": { "value": 20 },
      "minecraft:movement": { "value": 0.3 }
    }
  }
}
🧩
Entity Components
Health, movement, physics, and interaction components
• intermediate ⏱️ 45 min
▼

Essential Components

  • minecraft:health - Entity's health points and regeneration
  • minecraft:movement - Basic movement speed and type
  • minecraft:physics - Collision boxes and gravity
  • minecraft:pushable - How entity interacts with pushing
  • minecraft:collision_box - Hit detection boundaries

Example: Flying Entity

"minecraft:physics": {
  "has_gravity": false,
  "has_collision": true
},
"minecraft:flying_speed": {
  "value": 0.5
},
"minecraft:movement": {
  "value": 0.3
}
🤖
AI & Behavior Trees
Goal-based AI, behavior trees, and advanced mob intelligence
• advanced ⏱️ 60 min
▼

Behavior trees control entity AI through goals with priorities and conditions.

Common AI Goals

  • minecraft:behavior.random_stroll - Wandering behavior
  • minecraft:behavior.look_at_player - Track player movement
  • minecraft:behavior.panic - Flee when damaged
  • minecraft:behavior.follow_target - Chase specific targets

Priority System Example

"minecraft:behavior.panic": {
  "priority": 1,
  "speed_multiplier": 1.5
},
"minecraft:behavior.random_stroll": {
  "priority": 2,
  "speed_multiplier": 1.0
}

Block Fundamentals
Basic block structure, properties, and placement
• beginner ⏱️ 25 min
▼

Blocks are the fundamental building components of Minecraft worlds. Custom blocks can have unique properties, behaviors, and interactions.

Basic Block Structure

{
  "format_version": "1.19.0",
  "minecraft:block": {
    "description": {
      "identifier": "mypack:custom_block",
      "menu_category": {
        "category": "construction"
      }
    },
    "components": {
      "minecraft:destructible_by_mining": {
        "seconds_to_destroy": 2.0
      },
      "minecraft:material_instances": {
        "*": {
          "texture": "custom_block",
          "render_method": "opaque"
        }
      }
    }
  }
}

Key Properties

  • Hardness: Time required to mine the block
  • Blast Resistance: Resistance to explosions
  • Material: Affects sounds, particle effects, and tool effectiveness
  • Light Emission: How much light the block produces
🔄
Block States & Variants
Multiple states, rotations, and conditional properties
• intermediate ⏱️ 40 min
▼

Block states allow a single block to have multiple variations based on different conditions.

Defining States

"description": {
  "identifier": "mypack:lamp_block",
  "states": {
    "mypack:lit": [false, true],
    "mypack:color": ["red", "green", "blue"]
  }
}

State-Based Components

"components": {
  "minecraft:material_instances": {
    "*": {
      "texture": "lamp_off",
      "render_method": "opaque"
    }
  }
},
"permutations": [
  {
    "condition": "q.block_state('mypack:lit')",
    "components": {
      "minecraft:light_emission": 15,
      "minecraft:material_instances": {
        "*": {
          "texture": "lamp_on"
        }
      }
    }
  }
]
⚡
Block Events & Interactions
Player interactions, redstone, and custom events
• advanced ⏱️ 35 min
▼

Events allow blocks to respond to player actions and world changes.

Common Block Events

  • minecraft:on_interact: Triggered when player right-clicks
  • minecraft:on_placed: When block is first placed
  • minecraft:on_destroy: When block is broken
  • minecraft:on_step_on: When entity steps on block

Interactive Block Example

"events": {
  "mypack:toggle_light": {
    "set_block_state": {
      "mypack:lit": "!q.block_state('mypack:lit')"
    }
  }
},
"components": {
  "minecraft:on_interact": {
    "event": "mypack:toggle_light"
  }
}

Item Fundamentals
Basic item structure, properties, and behavior
• beginner ⏱️ 20 min
▼

Items are objects that players can hold, use, and interact with. They can be tools, weapons, food, or decorative objects.

Basic Item Structure

{
  "format_version": "1.19.0",
  "minecraft:item": {
    "description": {
      "identifier": "mypack:custom_item",
      "menu_category": {
        "category": "items"
      }
    },
    "components": {
      "minecraft:max_stack_size": 64,
      "minecraft:icon": {
        "texture": "custom_item"
      },
      "minecraft:display_name": {
        "value": "Custom Item"
      }
    }
  }
}

Essential Properties

  • Max Stack Size: How many can stack in one slot
  • Durability: For tools and equipment that wear out
  • Category: Where item appears in creative menu
  • Rarity: Affects name color and enchantment glint
⚒️
Tools & Weapons
Mining tools, combat weapons, and custom interactions
• intermediate ⏱️ 45 min
▼

Tools and weapons have special properties for mining, combat, and interaction.

Tool Components

  • minecraft:durability: Tool health and repair
  • minecraft:digger: What blocks it can mine
  • minecraft:weapon: Attack damage and speed
  • minecraft:enchantable: What enchantments apply

Custom Pickaxe Example

"minecraft:durability": {
  "max_durability": 500,
  "damage_chance": {
    "min": 5,
    "max": 10
  }
},
"minecraft:digger": {
  "use_efficiency": true,
  "destroy_speeds": [
    {
      "block": "minecraft:stone",
      "speed": 8
    },
    {
      "block": {
        "tags": "q.any_tag('stone', 'metal')"
      },
      "speed": 6
    }
  ]
}

Scripting Fundamentals
Getting started with Minecraft script APIs and modules
• beginner ⏱️ 30 min
▼

Minecraft Script APIs allow you to create dynamic behaviors and interactions using JavaScript.

Core Modules

  • @minecraft/server: Core world, player, and entity APIs
  • @minecraft/server-ui: GUI forms and interactive elements
  • @minecraft/server-gametest: Testing and development tools
  • @minecraft/server-admin: Administrative commands and controls

Basic Script Structure

import { world, system, Player } from "@minecraft/server";

// Event listener
world.afterEvents.worldInitialize.subscribe(() => {
    console.log("World initialized!");
});

// Repeating function
system.runInterval(() => {
    // Runs every tick (20 times per second)
    const players = world.getPlayers();
    players.forEach(player => {
        // Do something with each player
    });
}, 1);

World & Dimension APIs
World access, block manipulation, and dimension control
• intermediate ⏱️ 45 min
▼

World APIs provide access to blocks, entities, and world properties.

World Object Methods

import { world, BlockPermutation } from "@minecraft/server";

// Get all players
const players = world.getPlayers();

// Get specific dimension
const overworld = world.getDimension("overworld");
const nether = world.getDimension("nether");

// Block manipulation
const location = { x: 0, y: 64, z: 0 };
const block = overworld.getBlock(location);
block.setPermutation(BlockPermutation.resolve("minecraft:diamond_block"));

// Spawn entities
overworld.spawnEntity("minecraft:cow", location);

// Execute commands
overworld.runCommand("weather rain");

Common World Events

  • worldInitialize: When world starts
  • blockPlace: When player places block
  • blockBreak: When player breaks block
  • itemUse: When player uses an item

Player & Entity APIs
Player interactions, entity manipulation, and custom behaviors
• intermediate ⏱️ 50 min
▼

Entity and Player APIs allow interaction with all moving objects in the world.

Player Methods

import { world } from "@minecraft/server";

world.afterEvents.playerJoin.subscribe((event) => {
    const player = event.player;
    
    // Player information
    console.log(`${player.name} joined at ${player.location}`);
    
    // Send messages
    player.sendMessage("Welcome to the server!");
    player.onScreenDisplay.setTitle("Welcome!", {
        fadeInDuration: 20,
        stayDuration: 60,
        fadeOutDuration: 20
    });
    
    // Inventory manipulation
    const inventory = player.getComponent("inventory").container;
    inventory.addItem(new ItemStack("minecraft:diamond", 5));
    
    // Teleportation
    player.teleport({ x: 0, y: 100, z: 0 });
});

Entity Queries

// Find nearby entities
const location = { x: 0, y: 64, z: 0 };
const nearbyEntities = overworld.getEntities({
    location: location,
    maxDistance: 10,
    type: "minecraft:cow"
});

User Interface APIs
Forms, modals, action bars, and custom GUIs
• advanced ⏱️ 40 min
▼

UI APIs allow creation of interactive forms and displays for players.

Form Types

import { ActionFormData, ModalFormData, MessageFormData } from "@minecraft/server-ui";

// Action Form (buttons)
const actionForm = new ActionFormData()
    .title("Main Menu")
    .body("Choose an option:")
    .button("Option 1", "textures/ui/icon1")
    .button("Option 2", "textures/ui/icon2");

// Modal Form (inputs)
const modalForm = new ModalFormData()
    .title("Settings")
    .textField("Player Name", "Enter name...")
    .toggle("Enable PvP", false)
    .slider("Difficulty", 1, 10, 1, 5);

// Message Form (yes/no)
const messageForm = new MessageFormData()
    .title("Confirm Action")
    .body("Are you sure you want to continue?")
    .button1("Yes")
    .button2("No");

Displaying Forms

// Show form to player
actionForm.show(player).then((response) => {
    if (response.selection === 0) {
        player.sendMessage("You chose Option 1!");
    }
});
